# Demote button packs

Button packs add ready-made custom buttons to
[Demote](https://madewithbestpractice.com/demote/), the universal TV remote,
for things Demote doesn't control on its own: an AV receiver, a Bitfocus
Companion page, or Home Assistant service calls.

- **Data only.** A pack is a JSON file that describes buttons. It can't run
  code, and Demote never reads the replies.
- **Private.** Addresses and keys are entered by each user as variables, kept
  in their phone's secure storage, and never shared.
- **Local by default.** Packs talk to devices on the home network unless
  they say otherwise, and the app shows exactly where requests go before a
  pack is turned on.
- **Reviewed.** Anyone can open a pull request. Nothing reaches the app
  until it's reviewed and merged.

> Button packs are coming to Demote in a future update. This repo is open
> now so packs can be ready when it ships.

## Layout

| Path | What it is |
|---|---|
| `packs/` | Published packs, one `<id>.json` each |
| `drafts/` | First-party packs awaiting hardware tests (validated, not in the index) |
| `index.json` | The directory the app reads, generated by `tools/build_index.py` |
| `schema/pack.schema.json` | The pack format (JSON Schema) |
| `schema/icons.json` | Icon names a pack may use |
| `examples/` | Example packs for both engines (not published) |
| `tools/` | The validator, index builder and validator self-test |
